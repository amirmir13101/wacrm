# TalkWagon SEO Batch 04 Image Notes

## Decision

Batch 04 did not generate new competitor-page imagery because the only
authoritative V2.2 competitor page is the already-published `/wati-alternative`
page, and that page already has three page-specific, optimized, non-branded
visual placements from the approved Batch 03 visual expansion.

This avoids unnecessary asset churn and keeps the page visually compliant:

- no competitor logo or interface;
- no fake comparison score;
- no fake price or statistic;
- no “winner” badge or superiority symbol;
- no readable generated text;
- no customer data, people, faces, or private UI.
